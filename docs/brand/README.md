# Shelf brand

Bracket (concept 04) is the official Shelf mark. Two opposing brackets frame a square artifact.
Use the lowercase `shelf` wordmark with it. Keep the mark monochrome and preserve its proportions.

- [Official Bracket SVG](../../apps/web/src/assets/shelf-bracket.svg)
- [Favicon](../../apps/web/public/favicon.svg)
- [Backup Folio SVG](./shelf-folio.svg)

Folio (concept 06) is retained as a backup. It is not used in the application.

The shared `ShelfBrand` component uses the official SVG as a CSS mask so the mark inherits the
wordmark color. The favicon uses the same geometry with padding on a dark square. If the official
geometry changes, update both SVGs and the favicon version in `apps/web/index.html`.
